# 사진 가구 조건 누락·상담 입력 글꼴 보완

## 변경

- 사진이 있는 추천용 분석에는 이미지별 `photoInventory`를 요구합니다. AI가 관찰한 주요 지원 가구 유형·제안 수량·시각 근거를 구조화해 반환하고, 서버가 각각을 `REFERENCE_IMAGE`/`PREFERRED` 조건으로 연결합니다. 스타일·색감만으로 주요 가구를 대신하지 않도록 지침을 명확히 했습니다.
- 이미지마다 목록 또는 식별 한계를 제출해야 합니다. 식별할 수 없는 사진에서는 가구를 만들어 넣지 않고 설명 보완을 안내합니다. 수량과 가구 종류는 사용자가 조건 확인 단계에서 수정·제외할 수 있습니다.
- 반복 사진의 수량은 합산하지 않습니다. 같은 유형은 가장 큰 관찰 수량을 한 번 제안하며, 직접 쓴 수량·제외가 우선합니다. 텍스트 조건에 지원되지 않는 소재 등의 세부 설명이 있어도 유효한 수량을 보존합니다. 동등한 추정과 사진 조건은 사진 근거를 보존합니다.
- 한 번의 기존 멀티모달 호출에서 목록과 해석을 함께 받습니다. 잘못된 응답은 기존 요청·시간 예산 안에서 한 번만 보정합니다. 최종 조건 수는 기존 12개를 유지하되, 텍스트·사진 중복 정리 전에 한도가 잘못 적용되지 않게 했습니다. 기존 분석 API 응답 형식과 프런트엔드 계약은 유지합니다.
- 설명·조건 입력에 실제 Pretendard Regular를 자체 호스팅해 적용했습니다. 기존에는 이름만 지정되어 시스템 글꼴로 대체될 수 있었습니다. 적용 범위는 상담 textarea이며, 기존 색상·반경·14px 크기와 모바일 16px를 유지하고 줄 간격·자간·안쪽 여백을 정리했습니다.

## 검증

- Web: 842 통과, opt-in 벤치마크 1개 제외. lint·production build 통과.
- Backend: clean 전체 실행 968 통과, 실패/오류/제외 0. bootJar 통과. 로컬 Java25 override만 사용하고 저장소 Java21 설정은 유지했습니다.
- 새 회귀 10개: 주요 사진 가구별 조건 생성, 여러 사진 중복, 텍스트 제외/수량 우선, 이미지 누락/허위 인덱스/잘못된 유형·수량 거절, 식별 한계 안내, 보정 경로, 정리 전/후 한도, 미지원 소재와 명시적 수량, 사진 출처 보존.
- 읽기 전용 코드 리뷰에서 발견한 중간 조건 한도·명시적 수량 우선순위 문제를 실패 테스트로 재현 후 수정했습니다.
- PC 1440×900, 모바일 390×844: 실제 글꼴 로딩, 입력·조건 수정, 키보드 포커스 확인. 모바일 scrollWidth=390. 로컬 모의 응답 화면의 실행 오류 0개, Impeccable detector `[]`.
- 최초 최종 서버 실행은 생성된 `ConsultationPhotoInventoryTest 2.class` 중복 산출물로 실행기 오류가 났습니다. 소스 중복은 없었고 `clean test bootJar`로 재확인했습니다.

워크스페이스 화면 증거: `../../../docs/ui-tooling/qa/photo-coverage-2026-10-18/`. 설명 PC·모바일 전후, 조건 PC·모바일 및 `baseline.json`, `after.json`, `review-ui.json`이 있습니다. 운영 배포·실제 분석 확인은 같은 폴더에 별도 기록합니다.

## 한계와 글꼴 출처

구조 검증은 AI가 보고한 관찰 목록이 조건으로 빠짐없이 연결되는지를 확인합니다. 사진에 있는 모든 물체를 반드시 알아본다는 보장은 아닙니다. 여러 사진은 동일 공간의 참고 취향으로 해석하며, 서로 다른 방의 가구를 모두 합산하지 않습니다. 작은 장식보다 주요 가구와 명시적 요청을 우선합니다.

공식 [Pretendard v1.3.9](https://github.com/orioncactus/pretendard/tree/v1.3.9)의 `packages/pretendard/dist/web/static/woff2/Pretendard-Regular.woff2`를 사용합니다. 765,892 bytes이며 최초 상담 입력 시 내려받고 해시 자산으로 재사용합니다. SIL Open Font License는 `src/assets/fonts/Pretendard-LICENSE.txt`에 보존했습니다. 전체 페이지에 새로운 글꼴을 적용하지 않습니다.
